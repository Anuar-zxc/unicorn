# Выгрузка договоров goszakup.gov.kz

Загрузчик использует официальный V3 REST API портала, а не HTML-скрейпинг:

- список/полная информация: `GET https://ows.goszakup.gov.kz/v3/contract/all`;
- предметы договора: `GET /v3/contract/{id}/units`;
- продолжение выгрузки: ссылка `next_page` из ответа API.

## Токен

Портал требует Bearer-токен даже для открытых данных. Первичный токен выдаёт АО
«Центр электронных финансов», после чего его можно перевыпускать в профиле
участника. Официальная документация:
https://goszakup.gov.kz/ru/developer/ows_v3

Добавьте токен в локальный файл `.env.local`:

```dotenv
GOSZAKUP_API_TOKEN=ваш_токен
```

Не коммитьте токен в Git.

## Запуск

Проверка на двух страницах:

```bash
npm run goszakup:contracts -- --max-pages 2 --units
```

Полная выгрузка метаданных и предметов договора:

```bash
npm run goszakup:contracts -- --units
```

Полная выгрузка с обнаруженными PDF/файлами:

```bash
npm run goszakup:contracts -- --units --download-files
```

Повторный запуск продолжает работу по `checkpoint.json`. Для чистого старта
используйте `--reset`.

## Формат

Каждая страница атомарно сохраняется как gzip-сжатый JSONL:

```text
data/goszakup/contracts/
  checkpoint.json
  manifest.json
  pages/page-00000001.jsonl.gz
  files/
```

Одна строка JSONL содержит исходный объект `contract`, а при включённых опциях —
также `units` и список `downloaded_files`. Страничная раскладка позволяет
возобновлять многодневную загрузку без перезаписи уже готовых данных.

Перед обучением модели удалите или замаскируйте ИИН и другие персональные данные,
если они встречаются в открытых записях.
