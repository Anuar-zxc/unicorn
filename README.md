# Lexo — юридический AI для Казахстана

Lexo помогает людям понять договор до подписания, задать правовой вопрос со ссылками на законы РК и собрать договор в пошаговом диалоге, а юристам — быстрее проверять, исследовать и готовить документы.

Прод: https://lexo-ai-kz.vercel.app

## Стек

- **Next.js 15** (App Router), React 19, Tailwind
- **Supabase** — auth, Postgres с RLS, приватное хранилище файлов
- **Gemini** (Google AI Studio) — модель, стриминг ответов, OCR сканов
- **Правовой RAG** — BM25 + русский стемминг по 2 338 статьям 7 актов РК из «Әділет» (`data/kz-law`)
- **Polar** — подписки; **Stripe** — разовые оплаты консультаций
- **Vercel** — хостинг и аналитика

## Быстрый старт

```bash
cp .env.example .env.local   # заполните ключи
npm install
npm run dev
```

### База данных (Supabase SQL Editor), по порядку

1. `supabase/schema.sql`
2. `supabase/migrations/20260621_lexo_v6.sql`
3. `supabase/migrations/20260621_contract_builder_bilingual.sql`
4. `supabase/migrations/20261111_security_hardening.sql` — **обязательно**: запрещает пользователям менять себе тариф и переводит лимиты на неудаляемый журнал `usage_events`

Все миграции идемпотентны — их можно запускать повторно.

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run dev` / `build` / `start` | разработка, сборка, прод-сервер |
| `npm run typecheck` | проверка типов |
| `npm test` | юнит-тесты (Node ≥ 22.6, без зависимостей) |
| `npm run kz:ingest` | обновить корпус законов из «Әділет» |
| `npm run kz:evaluate` | метрики поиска по корпусу |

## Как устроены лимиты

`lib/usage.ts` — лимиты тарифов и какие инструменты к какому лимиту относятся. Каждое обращение к AI записывается в `usage_events` (только добавление), месяц считается с 1-го числа по UTC. Если модель не ответила и показан резервный текст — лимит не списывается.

## Структура

```
app/(marketing)    лендинг, /seller-tax
app/dashboard      рабочее пространство (защищено middleware)
app/api            AI-эндпоинты, оплата, вебхуки
lib/stream-tool.ts общий обработчик AI-инструментов: auth → лимит → RAG → стрим Gemini → запись
lib/kz-retrieval.ts поиск по законам РК (чистые функции, покрыты тестами)
supabase/          схема и миграции
tests/             node:test
```
